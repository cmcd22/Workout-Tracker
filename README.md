# 🏋️‍♂️ Workout Tracker  
*A simple, personal iOS app for logging gym workouts.*

**As someone who has been lifting for a number of years, I've always struggled to figure out the best way to track my workouts. So I ultimately decided to create my own iOS app that caters to my exact needs.** 
**Since I haven't coded in Swift before, I utilised ChatGPT and vibe-coded this app. I will continue updating with new features and bug fixes as time goes on.**

---

## 📱 Features

### ✔ Log a workout by session type
- Push  
- Pull  
- Legs/Abs  
- Chest/Back  
- Arms  
- Abs/Legs  
- Other  

### ✔ Add exercises with one tap
Frequently logged exercises are available to select directly.  
New exercises can be added manually and existing exercises can be searched for.  

### ✔ Record sets (weight + reps)
A clean set-entry screen allows quick logging of:
- Number of sets  
- Weight (kg)  
- Reps
- Optional parameters (Bench Angle, Seat Height, Foot Placement etc).  

### ✔ Save full workouts using Core Data
Logged workouts are stored locally using Core Data, with automatic relationship handling.
